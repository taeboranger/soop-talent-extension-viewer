# SoopTalent 시청자 확장 (운영 종료 예정)

달란트 시장이 공유 링크 + 웹 로그인 방식으로 전환되었습니다. 새 시장에서는 이 확장 프로그램이 필요하지 않습니다.
시청자는 스트리머가 공유한 시장 링크를 열고 SOOP으로 로그인해 바로 구매합니다.

SOOP 시청자용 Chrome 확장(MV3)입니다.
스트리머가 연 **달란트 시장** 게시글에서 보유 달란트를 확인하고 보상을 신청합니다.

```
manifest.json
src/
  content.js    시장 게시글의 댓글 등록 버튼 옆에 "구매" 버튼 주입
  content.css
  popup.*       툴바 팝업 — 서비스 연결 상태
icons/                아이콘 16·48·128 (생성물)
tools/make-icons.mjs  아이콘 생성기
store-assets/         스토어 제출용 이미지 — HTML이 정본, PNG는 생성물
```

스토어 등록 절차와 복붙용 문구는 [STORE.md](STORE.md)에 있습니다.

## 함께 쓰는 저장소

| 저장소 | 역할 |
|---|---|
| sooptalent-server | 서버. **규약의 정본은 그쪽 `API.md`입니다** |
| sooptalent-streamer | 스트리머 확장 |
| **sooptalent-viewer** | 이 저장소 |

---

## 설치

1. Chrome에서 `chrome://extensions` 열기
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드** → 이 폴더 선택
4. 도구 모음의 아이콘을 눌러 서비스 연결 상태 확인

스트리머가 시장으로 연 글에 들어가면 댓글 등록 버튼 옆에 **구매**가 생깁니다.

팝업을 열 때마다 서버에 닿는지 확인해 위쪽에 표시합니다.
구매 버튼이 안 보일 때 원인이 주소인지 서버인지 여기서 바로 갈립니다.

---

## 하는 일

1. 방송국 게시글을 열면, 그 방송국에서 **지금 열려 있는 시장 글 번호**를 서버에서 받아 60초간 캐시합니다.
2. 지금 보는 글이 그 목록에 없으면 여기서 끝입니다 — **요청이 더 나가지 않습니다.**
3. 시장 글이면 보상 목록과 내 달란트를 받아 **구매** 버튼을 붙입니다.
4. 보상을 고르면 신청 문구가 댓글 입력창에 채워집니다.

```
[구매신청] 치킨 기프티콘 x2, 손편지
```

**댓글 등록은 본인이 직접 누릅니다.** 확장이 대신 글을 쓰지 않습니다.

---

## 알아둘 점

**표시되는 잔액은 참고용입니다.** 실제 차감은 스트리머가 시장을 닫을 때
서버가 SOOP 댓글을 직접 읽어 계산합니다.

- 정산은 **댓글 시각 순 선착순**입니다. 앞사람이 다 가져가면 뒤 신청은 거절되고 달란트는 그대로 남습니다.
- 확장 없이 위 형식을 **손으로 써도 똑같이 접수됩니다.** 확장은 문구를 대신 맞춰 주는 편의 도구일 뿐입니다.
- 그래서 확장을 고쳐 잔액이나 수량을 조작해도 결과는 달라지지 않습니다.

**달란트는 스트리머별로 따로 쌓입니다.** A 스트리머에게 모은 달란트로 B의 보상을 받을 수 없습니다.

## 개발

아이콘을 다시 만들 때 (스트리머 확장과 도형이 달라야 합니다):

```powershell
node tools/make-icons.mjs viewer ./icons
```

스토어 제출용 이미지를 다시 뽑을 때 (헤드리스 Chrome + Noto Sans KR 필요):

```powershell
.\store-assets\build.ps1
```

문법 확인:

```powershell
node --check src/content.js
```
